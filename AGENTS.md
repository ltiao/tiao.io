# Repository instructions

This is the canonical instruction file for agents working in this repository.
Read and follow every guide whose trigger matches before making a change:

- **Content authoring:** when adding or editing publications, technical posts,
  news, talks, projects, tags, links, icons, buttons, external URLs, or author
  metadata, read and follow [`docs/agent-guides/content-conventions.md`](docs/agent-guides/content-conventions.md).
- **About content:** when editing any About Me, homepage biography/research,
  career-summary, collaborators, or `data/authors/me.yaml` bio content, read
  and follow [`docs/agent-guides/about-content.md`](docs/agent-guides/about-content.md).
- **Build/toolchain:** when changing dependencies, install behavior, Tailwind,
  Hugo CSS, pnpm, or Parcel watcher settings, read and follow
  [`docs/agent-guides/build-toolchain.md`](docs/agent-guides/build-toolchain.md).
- **Math/rendering:** when modifying a content page that contains mathematical
  notation or literal dollar signs—even if the edited passage is ordinary
  prose—or when changing math configuration/render hooks or performing
  rendering/browser validation, read and follow
  [`docs/agent-guides/math-rendering.md`](docs/agent-guides/math-rendering.md).
